# controller-bridge

## Working rules

- Implement every feature and bug fix test-first with the `/tdd` skill (`mattpocock-skills:tdd`): red, green, refactor.
- Always use the `/caveman` skill (`caveman:caveman`) for replies.
- Put every issue in a GitHub milestone. Create one for each body of work (a spec and its tickets share one), and assign new issues to it when filing them.
